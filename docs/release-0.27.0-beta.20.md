# 0.27.0-beta.20

Profile overhaul.

- **Stats as cards.** Steam games, hours played and games played sit in three clear cards, with labels in small capitals.
- **Gamerscore card.** A proper panel with a clean badge. An empty score reads "Not yet" instead of a dash.
- **Game scores open by default,** so your tracked games are visible without an extra click.
- Tabs, section headings and spacing follow the rest of the launcher.

Downloads: `Xbox-Preview-UI-Setup-0.27.0-beta.20.exe` (installer) and `Xbox-Preview-UI-Portable-0.27.0-beta.20.exe`, with checksums in `SHA256SUMS.txt`. Beta 18 and later update themselves. The builds aren't code-signed, so Windows SmartScreen may warn on first run.
