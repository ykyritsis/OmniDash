# OmniDash 0.7.2

A small follow-up to 0.7.1: every Settings page now carries its own icon.

## Settings icons

- **PS5:** most sections showed the generic gear after the shared Settings sections landed. Appearance, Screen & Sound, Accessories, Notifications, Library, Accounts, Accessibility and System now each show their own icon.
- **PS3, PS4 and 3DS:** their Settings menus had the same stale icon table, so their pages now use the right icons too.

Nothing else changes.

## Updating

The built-in updater installs this over 0.7.1: choose **Restart to update**, or let it apply when OmniDash next closes. `SHA256SUMS.txt` is attached for checking the downloads.
