# 0.27.0-beta.22

The launch screen says what it's waiting for.

- **Live launch stages.** While a game starts, the launch screen shows each step: starting Steam in the background, waiting for Steam to sign in, starting the game, then waiting for it to open. After 25 seconds it adds that some games take a while the first time. Combined with **Cancel**, a launch never sits on an unexplained spinner.
- Installs and downloads already go to the Queue, where **Remove from queue** cancels them and deletes the partial files.

Downloads: `Xbox-Preview-UI-Setup-0.27.0-beta.22.exe` (installer) and `Xbox-Preview-UI-Portable-0.27.0-beta.22.exe`, with checksums in `SHA256SUMS.txt`. Beta 18 and later update themselves. The builds aren't code-signed, so Windows SmartScreen may warn on first run.
