# Beta 32

The remote-play banner can now be dismissed without ending the stream.

- Choose **Hide** to remove the entire banner. The native video expands into the freed space.
- Hold **LB + RB + View** for half a second, or press **Ctrl + Alt + Shift + H**, to show or hide the controls again. A held shortcut toggles once until released.
- **LB + RB + A** (or the alternative selected in Stream settings) and **Ctrl + Alt + Shift + Q** still disconnect with the banner hidden. Showing controls does not stop the stream or change the disconnect binding.

The bar starts visible each session so the controls remain discoverable. Keyboard Tab reaches both Disconnect and Hide. The controller toggle uses XInput on Windows handhelds and Xbox-compatible pads. See [remote play controls](remote-play.md).

Validated native full-window resizing and restored toolbar space, Windows hotkey registration and dispatch, controller hold/release behavior, UI hide/reopen flow, keyboard navigation, larger text and stream lifecycle. Physical handheld gameplay was not tested.
