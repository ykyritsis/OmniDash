# OmniDash 0.7.0

## New: Aero theme
The Xbox dashboard in Frutiger Aero: a sunny island sea, one big square tile for your last game, glossy square tiles, frosted glass cards (My games & apps, Friends, Game Pass, Achievements) and a Series-style launch screen that rises the game's logo over its key art.

## Settings, simplified
Every dashboard now has the same eight sections and a short list of genuine options. Helix and the Xbox themes share one calm Settings screen; PlayStation and Nintendo themes show the same list in their native menus.

## Keyless PC Gamerscore
Reads the achievement files Steam keeps on your PC — no Web API key, works with private profiles. Each game is worth 1,000G, shared by rarity in multiples of 5. New unlocks show an "Achievement unlocked" toast.

## Also
- Pressing a game on Home launches it; a running game resumes instead. Game pages open from the library or the game menu.
- One clean game menu for every theme: Play / Resume, Game details, Manage game, Uninstall.
- Steam games launch even without Steam's launch controls (no more Steam restart loop).
- Series X|S controller button icons.
- New OmniDash logo and app icon.
- Faster: no live blur on Home, cached achievement reads.
