The sample library contains Forza Horizon 5, Minecraft, Halo Infinite, Cyberpunk 2077, Elden Ring, Red Dead Redemption 2, Sea of Thieves, Gears 5, DOOM Eternal, Starfield, The Witcher 3 and Hogwarts Legacy. It does not use the user's personal game library. The profile uses a generic built-in avatar.

Device mockups are generated illustrations based on these screenshots, not photographs or evidence of a test on physical hardware. Screenshots remain separate from the generated mockups.

Use JPEG files for posting and PNG files as masters. The app icon is unchanged. This kit accompanies the beta 25 GitHub release. github-social.jpg is available for the repository social-preview setting.

artboards.html contains editable promotional copy and layout. scripts/promo-render.cjs exports the layouts. scripts/promo-demo-assets.cjs retrieves public game art; scripts/promo-capture.cjs captures the renderer. PROMPTS.txt records the built-in image-generation prompts. DISCORD-POST.txt contains a three-message Discord thread draft and attachment suggestions.
