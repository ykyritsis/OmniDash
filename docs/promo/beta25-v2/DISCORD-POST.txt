Xbox Preview UI — beta 25

POST 1
I've been working on Xbox Preview UI, a full-screen Windows game launcher with controller navigation. It brings your installed games into one library, with game pages, download controls and supported Steam launch choices inside the app.

Beta 25 is available here:
https://github.com/ykyritsis/xbox-cloud-preview-on-pc/releases/tag/v0.27.0-beta.25

Grab the Setup executable to install it.
