# Australian MA15+ marking

`acb-ma15.png` is the unmodified MA15+ marking supplied by Australian Classification. It is bundled for an accurate, offline display on game pages, alongside the game's classification and consumer advice.

- [Official ratings reference](https://www.classification.gov.au/classification-ratings/what-are-ratings)

- [Markings downloads and guides](https://www.classification.gov.au/for-industry/classification-markings/markings-downloads-and-guides)

Retrieved 16 October 2026. The marking identifies the classification of a game; it does not imply endorsement of this launcher.
